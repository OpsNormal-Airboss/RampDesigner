**A safety-critical desktop application for designing FAA CoW-compliant aircraft parking layouts for airshows.**

## Features

- **150+ aircraft** — accurate dimensional data with SVG silhouettes
- **Real-time FAA CoW clearance** — green/yellow/red violation zones updated in < 80 ms
- **Seven display types** — Static Display, Warbird/Heritage, Taxi-Only, Military Static, Hot Ramp, Media Platform, Ramp Show
- **Full export suite** — SVG, PDF (Letter to ANSI-E1), PNG (72–600 DPI), JPEG, batch
- **Scale bar variants** — imperial, metric, or dual on every export
- **Satellite underlay** — geo-referenced tile streaming with opacity control
- **Named layout snapshots** — save, compare, and export versions within one project file
- **Runs offline** — no network required for core functionality
- **macOS, Linux, Windows** — native installers for all three platforms
